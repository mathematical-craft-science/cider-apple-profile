# Доменный backlog

## Выбор сортов яблок для sugar-acidity plot

Нужно спроектировать модель фильтрации и выбора точек sugar-acidity zone для
`AppleVariety`.

Количество сортов яблок может стать очень большим, поэтому порт вида
`List<@NonNull AppleVarietySugarAcidityZoneAssessment> list()` не подходит как
долгосрочная форма загрузки данных для графика. Графику чаще нужен осмысленный
набор сортов, а не весь каталог целиком.

Возможные направления:

- Query object для точек сортов яблок на графике, например
  `AppleVarietySugarAcidityZonePointQuery`.
- Фильтрация по sugar-acidity zone.
- Фильтрация по уровням sugar, acidity и tannin.
- Поиск по названию сорта или синониму.
- Фильтрация по сезону созревания, происхождению, стране/региону или сидровой
  традиции.
- Фильтрация по полноте и надежности измерений.
- Явный выбор по ids сортов.
- Pagination или cursor-based загрузка.
- Сортировка по названию, зоне, sugar, acidity, tannin или релевантности.
- Опциональная загрузка по viewport, если график станет интерактивным.

API и application port в итоге должны выражать эту модель выбора, а не
предоставлять неограниченную операцию `list()`.

## Сезоны и партии для feedstock samples

Для `FeedstockSample` нужно предусмотреть возможность указывать сезон и партию.
Это важно для выборки точек на графике: химический профиль сырья зависит не
только от сорта, но и от конкретного урожая, поставки, хранения и момента
измерения.

Возможные характеристики `FeedstockSample`:

- Сезон урожая.
- Партия или batch.
- Cider maker / владелец сырья.
- Дата сбора.
- Дата прессования или измерения.
- Условия хранения перед измерением.
- Источник сырья: свой сад, поставщик, ферма, рынок.

## Возможные характеристики apple varieties

Для `AppleVariety` стоит отделять устойчивые сортовые характеристики от
характеристик конкретного урожая или партии. В контексте cider-домена здесь
нужны прежде всего признаки, которые помогают оценивать сидровой потенциал
сорта, искать кандидатов для графиков и приводить химический профиль к
понятным локальным терминам.

Возможные характеристики:

- Синонимы и локальные названия.
- Страна, регион или сидровая традиция происхождения.
- Сезон созревания: ранний, средний, поздний.
- Рекомендуемый период хранения перед прессованием.
- Основное назначение в контексте сидроделия: single-variety cider, blending,
  fresh juice, cooking cider, vinegar, distillation.
- Cider classification по локальным системам: English, French, Spanish,
  North American.
- Типичный sugar-acidity zone.
- Типичный диапазон sugar, acidity, tannin и pH.
- Надежность химического профиля: единичное измерение, диапазон, статистика,
  источник данных.
- Описание вкусового/технологического вклада в сидр: body, sharpness,
  bitterness/astringency, aroma intensity.
- Роль в профиле сидра: sugar contributor, acid contributor, tannin
  contributor, balancing apple.
- Пригодность для single-variety cider.

Характеристики вроде урожайности, силы роста дерева, времени цветения,
опылителей, устойчивости к болезням, зимостойкости и пригодности к климату
скорее относятся к orchard-домену. Их не стоит смешивать с cider-моделью
`AppleVariety`, пока в системе явно не появится область планирования сада.
